# Ro

En enkel, avhengighetsfri oppgavetimer. Legg inn konkrete oppgaver med egen
tid på hver, velg pauselengde, og jobb deg gjennom køen i rekkefølge.

## Kjør lokalt

Åpne `index.html` direkte i nettleseren, eller start en enkel lokal server:

```bash
python3 -m http.server 8787
```

Gå deretter til `http://localhost:8787`.

## Test

```bash
node --test app.test.mjs
```
